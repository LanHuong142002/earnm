# Tasks: Members can attach photos to tasks

Spec: `.ourkit/specs/claude-ourkit-spec-9-photos.md`. Plan: `.ourkit/plans/claude-ourkit-spec-9-photos.md`. Mockup: `.ourkit/mockups/claude-ourkit-spec-9-photos.html`. This branch is stacked on #8 (comments), which is already in the code.

**API contract shared by tasks 1–3** (base `/projects/:projectId/tasks/:taskId/photos`, all need sign-in, non-members get 404 `not_found`, every route answers 503 `photos_unavailable` when Cloudinary isn't configured):

- Photo JSON: `{ id, taskId, addedBy: { id, displayName } | null, caption, width, height, createdAt, thumbUrl, url }`. `thumbUrl` (240 px, square crop) and `url` (fit 1600 px) are signed Cloudinary delivery URLs for `type: authenticated`.
- `GET /` → `{ photos: Photo[] }` ordered by `createdAt`, `id`.
- `POST /sign` body `{ id: uuid }` → `{ cloudName, apiKey, timestamp, signature, publicId, type: "authenticated" }` where `publicId = earnm/<projectId>/<taskId>/<id>`. Involved only (403 `forbidden`); 409 `photo_limit_reached` when the task already has 10 recorded photos.
- `POST /` body `{ id: uuid, publicId, width, height, caption? }` (strict) → 201 Photo, or 200 with the existing photo for the same id on the same task; 409 `id_conflict` for an id on another task; 400 `validation_failed` when `publicId` isn't exactly the derived one or the caption is over 200 characters after trimming; 403 for someone not involved; 409 `photo_limit_reached` at 10.
- `PATCH /:photoId` body `{ caption: { value, editedAt } }` (strict) → 200 Photo; involved only; last-write-wins; 404 if gone.
- `DELETE /:photoId` → 204; involved only; deletes the row, then destroys the Cloudinary image (a failed destroy is logged, never returned).
- Involved = the task's creator or an assignee (`apps/api/src/tasks/involved.ts`, already exists).

In `apps/api/src/config.ts` read optional `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` (all three or photos are off); document them in `apps/api/.env.example`, `render.yaml` (as secret, `sync: false`) and `docs/deploy.md`.
